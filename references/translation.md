# 翻译、术语与原文语义核对

## 目标与优先级
保持原文概念、对象、逻辑关系和判断力度，再选择本领域可理解的中文。避免字面正确但在当前语境下指向另一事物的译法。统一同一概念的称谓，不把同一个英文词在不同语境中强制译成同一个中文。

## 工作步骤
1. 先识别对象：词语在这里指实体、实验操作、图像单位、统计量、计算表征、临床状态，还是作者立场？从上下文、Methods、图注、变量定义和软件输出核对，不能只看摘要或词典。
2. 对影响主要结论的术语建立简短内部对应：英文原词/短语→本文所指→选用中文。只记录关键、歧义或新增术语，不给所有普通词建表，也不强制把该表放进成稿。
3. 优先使用领域通行译法。专业含义仍有疑问时查原文定义、官方方法/软件文档及可靠术语资料；检索同领域使用仅作辅助。不能因某篇中文二次解读使用了一个词就认定正确。
4. 对尚无稳定译名的术语，采用不易误导的描述性中文，首次保留英文或缩写。不能把自选译名写成已经公认的标准术语。
5. 在标题、正文、图注、术语表中检查同一概念的一致性。特别检查作者自定义分类与领域通用分类是否被混为一谈。
6. 按原文回查关键句：谁对什么做了什么、与谁比较、在何种条件下、数量如何变化、作者说得多确定。改写后既不能夸大，也不能无故弱化。
7. 最后做中文读者检查：所选词在生物医学中是否已有另一强势含义？是否会让人误认病变、样本实体、细胞谱系、实验行为或统计单位？有歧义时优先消歧，而不是增加生硬修辞。

## 重点核对的语义
- 研究对象：type/state、sample/donor/section/patch/spot、tumor-derived/cDC1-like、细胞与基因或蛋白。保留作者研究范围，区别实验测量与推断。
- 操作与观察：depletion未必是基因敲除，knockdown不等于knockout；resident/migratory表达程序不自动证明细胞驻留或真实迁移。
- 统计关系：association不自动成为因果；enrichment、relative abundance不自动变成绝对细胞数；odds ratio、risk ratio、correlation、AUC与accuracy不可混用。
- 数量：核对比较基准。“1.33-fold as high”可写“为对照的1.33倍/高约33%”，避免“增加1.33倍”的歧义。显著性、方向、单位、分母与原文一致。
- 证据和语气：保留may、suggest、could、necessary、sufficient及否定条件；用中文自然表达，不机械给每句话补“可能”。观点转述还须保留“作者认为”和适用范围。
- 方法输出：embedding、latent representation、signature、score、effect size等应根据实际定义解释。统计方法中的conditional不表示一定已经消除了所有技术差异。

## 语境示例（禁止机械全局替换）
| 英文与语境 | 建议处理 |
|---|---|
| tissue patch：从组织图像滑窗截取的局部区域 | 首次“组织图像块（tissue patch）”，后文“图像块”；不译病理意义的“斑块” |
| plaque：动脉粥样硬化或淀粉样病变 | 按病理语境保留“斑块”；不能因为前例禁用该词 |
| tissue block：真实取材或包埋的组织 | 可用“组织块”，与计算图像块区分 |
| niche / microniche | 通常“微环境/生态位”；VIMA作者定义的microniche用“微生态位”，不把所有生态位理解为连续物理区域 |
| gene-expression signature / mutational signature | 前者可用“表达特征基因集”等；后者用“突变特征/突变谱特征”，不能都译“基因集” |
| pooling：实验合并样本 / pooled analysis：合并数据分析 | 前者“混样”；后者按情境用“合并分析/汇总分析” |
| pseudobulk | 首次解释为按供者/样本及细胞群汇总计数，随后保留pseudobulk，避免“伪批量” |
| oligodendrocyte | 使用“少突胶质细胞”，避免直译“寡突” |

## 写作与审稿的输出
- 写作时先确定关键术语及语义，再组织文章；不要先自由译写，最后只替换几个名词。
- 审稿时，对实质误译给出英文原词及必要上下文、误读风险、准确且可直接替换的中文。普通可接受同义词不列为错误。
- 没有可核对的英文来源时，不能断言“原文是某词”；可指出中文歧义并给暂定表述，清楚标明尚未确认之处。
- 标准中文本身歧义较大时，可用更明确的描述并保留英文。抗原“提呈/呈递”等均可成立，不为统一个人偏好反复改写。
- 不把术语核对备注和译者工作过程写进公众号正文；保留必要的首次术语解释即可。
