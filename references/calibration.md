# 判断示例

以下为示意案例，只用于展示推理方式，不作为对所有领域的固定事实或检查项。具体名称、数字与译法必须回到当前来源核实；不得将示例移植为待写文章的事实。

| 示例情境 | 可迁移的判断 |
|---|---|
| 研究论文被要求按分析设计解读 | 按读者目的组织，不由期刊栏目决定文体 |
| 模型使用某些表型标签训练，另一些变量留出 | 区分监督输入、内部评估与独立验证 |
| 先在每份样本分解因子，再跨样本聚类 | 解释分析层次，保留理解流程必需的数字 |
| 部分样本通过筛选后才进入方向性分析 | 保留分母与已知筛选依据，不自编阈值 |
| 两实验组的比例分别为8%与20% | 不能写成比例随时间从8%上升至20% |
| 两次检验相关系数相同，但指标或对象不同 | 分别说明比较对象与统计量 |
| 专家建议某技术在部分场景尝试 | 保留立场及适用范围，不扩大为普遍替代 |
| 图像分析中的patch与病理学plaque同时出现 | 按对象分别选译，不全局替换同一中文词 |
| 导读只列陌生化合物名称 | 先说明类别和直接意义，把机制问题留给正文 |
| 采样轶事成为开头 | 连接材料与研究目的，不虚构行动动机或具体样本的发现贡献 |
| 正确稿件反复审查 | 只改真实问题，不反复替换同样成立的措辞 |
