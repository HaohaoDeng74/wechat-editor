# 校准案例

将案例作为判断示例，不把某次修改变成所有文章的强制句型。只有用户明确确认的偏好才可提升为通用要求；一次未反馈的建议不视为已确认。

| 情况 | 判断及处理 |
|---|---|
| GBM研究原文是Research，但用户要讲分析设计 | 采用方法主文体，重点解释克隆内分析、映射与验证，而非补更多生物故事 |
| scSLIDE使用诊断/严重程度标签，发病时间或病理评分留出 | 区分监督输入和独立验证；保留方法贡献，不逐段重复“不能说明” |
| NMF每样本16个因子，12样本192个，再聚成16种微环境 | 数字多但解释两层分析，应该保留必要层次 |
| 58个亚克隆、23个可用、18个支持方向 | 保留分母；有来源才补筛选指标，不自行编阈值 |
| cDC1样状态写成天然cDC1，或对照实际为抗PD-1单药 | 属实质科学修正，说明原因并替换 |
| 多部位共享TCR克隆型 | 支持系统性反应，不直接写成从TLS出发的定向迁移谱系追踪 |
| “共同完成同一件事”概括遗传互作 | 检查是否把功能关系误写成同一通路/复合物，必要时直接写观测 |
| “位置决定细胞状态”仅有空间表达比较 | 改为不同位置呈不同状态；有位置干预再判断因果 |
| 同一篇稿件重复审查 | 不把不同但同样成立的措辞反复替换；只处理真实未解问题 |
| 专家说“部分场景值得尝试，尚不能普遍替代” | 保留建议及场景限制；不可改成全面替代，也不可删除其积极判断 |


补充校准：
- CD40L比例7.7%与19.9%若来自同一时点两个实验组，不写成随时间上升。
- 原文中对照为抗PD-1单药时，不笼统写成空载体或无治疗对照。
- 轨迹与CPS的Pearson相关和近邻预测CPS的Spearman相关，数值相同也不可混为一次验证。
- 新闻稿既需纠正虚构临床能力，也需保留真实发布进展，不让全部篇幅都变成限制说明。


翻译校准：VIMA的tissue patch是滑窗截取的组织图像块，不是动脉粥样硬化或淀粉样斑块。若同一句同时含patch和plaque，分别翻译；不要将“斑块”全局替换。审稿需在中文读者语境中识别这类歧义，而不仅核查字典对应。

- 海牛糖酶文章导读只写epilactose：先核对中文名“表乳糖”，说明其为二糖以及水解后单糖的碳源作用；机制选择性可留到正文。不要把水解写成合成益生元，也不把模型菌生长直接写成宿主获益。
- 跳水收集粪便的故事：连接粪便中的微生物DNA、宏基因组筛选与候选糖酶验证；不虚构跳水是唯一取样方式，或那一次样本就是发现来源。
